Investigate an address

Search the IP table and select an address to review its sources, activity, score, intelligence and policy history. Manager policy and firewall enforcement are separate; confirm your firewall accepted the list.

Filters and selection

Column filters combine. Text matches are highlighted. Dropdowns update immediately; text updates after a short pause. Select On date for a day, or From and Through for an inclusive range in your saved timezone. Destination ports use exact matches.

Use checkboxes, Ctrl-click or Shift-click to select rows for a whitelist with shared notes. Selection applies to the current page.

Columns

Open Columns to choose and order fields. Your layout is saved for your account. Disabled sources and unconfigured fields are omitted.

Whitelist and blacklist

Add an IP, public subnet, CIDR, netmask, range or ASN with a reason and optional expiry. IP details support exact-address rules. Whitelists and verified crawlers take precedence unless an emergency exact-IP block is set.

Scoring and expiry

The automatic threshold is 75. A first T-Pot or OWAPot attempt scores 50; further distinct attempts on the same honeypot and port add 25. Another honeypot or port adds 50, capped at 100. Fresh malicious intelligence shares a maximum 25-point bonus. ASN ownership and firewall drops add no points.

Qualifying activity renews the 30-day automatic expiry. Palo block hits renew existing blocks using event time. Manual blocks persist until removed or expired.

Dates

Select your timezone in System settings. First seen, last seen, recorded blocks and expiry use that timezone; stored timestamps remain UTC.

Policy history

IP details show saved rules, notes, intelligence reviews, list changes and expiry events.

Repeat offenders

Previously blocked addresses with subsequent observations are tracked over 30, 60, 90, 180 and 365 days. Longer windows use available retained history. Returning blocked addresses can regain block eligibility; whitelists and crawler protections still apply.

New IPs

New IPs arrived in the last 24 hours without a saved observation in the preceding year. A fresh installation has partial history.

Intelligence

MISP, GreyNoise, AbuseIPDB, VirusTotal, local ASN data and published crawler ranges are optional. Configure providers in System settings. Cached results are reused; unchecked and no-match results do not prove an address is benign.

GreyNoise

Fresh malicious findings can contribute to the shared 25-point bonus. Benign blocking conflicts are flagged for review and never automatically whitelisted. Automatic checks respect the configured weekly budget and provider backoff. Save review outcomes and notes on IP details.

Firewall feeds

Use /feeds/combined-block.txt as the enforcement feed. Only configured firewall source networks may download it. Authenticated administrators can download lists from the main page. Configure list refresh and rule placement on the firewall; the Manager does not change firewall rules.

Feeds read the latest complete atomic generation and support conditional requests. Download success does not confirm firewall acceptance or enforcement.

Reporting API

Create a named read-only token in System settings and send it as a bearer token. Reporting includes /api/v1/summary, /api/v1/ips, /api/v1/grafana and /api/v1/intelligence. Tokens are displayed only when created; revoke or replace them in Settings.

System settings

Configure server URLs, source agent names, collected fields, intelligence keys, reporting tokens, timezone, session duration and password. Empty source fields disable collection for that source.

Troubleshooting

If results are missing, check configured sources and collection status. If an address remains blocked after an exception, check the published feed, firewall refresh and acceptance. Use the IP history to identify the effective rule.

Administrator reference

Deployment and maintenance

See README.md and docs/INSTALL.md for setup, HTTPS, source credentials, backups and worker schedules. Run the tests against a staged copy before replacing production code. Keep an existing administrative session open during access changes until a fresh authorized session succeeds.

Community license

Home labs and nonprofit organizations may use this edition free within the usage allowance. Enterprise and commercial use require a separate license. The allowance is a rolling 30-day average of 500 distinct public IPs per UTC day, with at most one day per UTC calendar month above 500 and no day above 1,000. See LICENSE for the complete terms.

Usage is shown in System settings. Protection continues when a license is required. No usage telemetry is sent to the publisher.

Behavioral intelligence

Open System settings → Behavioral intelligence to configure background inspection. IP details show saved assessments and similar activity. Shadow analysis does not change blocking.

Confidence and similarity are uncalibrated. Review the evidence before changing policy. A shared fingerprint can come from unrelated users of the same tool.

The reporting API provides GET /api/v1/behavior and GET /api/v1/ips/<ip>/behavior with existing read-only tokens.
