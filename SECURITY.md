# Security reports

Do not include credentials, tokens, customer traffic or private infrastructure details in public issues. Report suspected vulnerabilities through the repository's private vulnerability reporting feature when available, or contact the publisher to arrange a private channel.

Public-IP validation, whitelist/crawler precedence, session authentication, CSRF protection, source restrictions, read-only reporting tokens, timestamp validation, intelligence freshness and atomic publication are security-critical behavior. Changes must retain tests for these properties.
